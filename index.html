Overview

This artifact contains comprehensive mechanized proofs and implementations for local contextual type inference. The artifact is organized into a core system with variants and extensions, providing both theoretical foundations and practical implementations.

Core System

Mechanized Proofs

  • Main Proof (Agda): main/proof_agda/ Available

    Complete formalization including declarative system, intermediate system with matching subtyping, algorithmic system, and implicit system F. Contains all lemmas and theorems from the paper except decidability.

    Requirements: Agda and Agda standard library
    cd main/proof_agda && make
    Recommended reading: Start with Implicit/README.agda which lists all theorems in paper order.
  • Decidability Proof (Rocq/Coq): main/decidability_coq/ Available

    Decidability proof of the algorithmic system.

    Requirements: Rocq Prover (Coq) and CoqHammer library
    cd main/decidability_coq/Dec && make

Implementation

  • Haskell Implementation: main/impl_haskell/Poly/ Available

    Complete Haskell implementation of the algorithmic system with all paper examples and additional types (lists, products, ST Monad).

    Requirements: GHC and Cabal
    cd main/impl_haskell/Poly && cabal build cabal run Poly (runs all examples) cabal run Poly -- A1 A2 A3 (runs specific examples)

Variants and Extensions

Right-to-Left Variant

  • Proof: variants/proof_variant_right2left/ Available

    Complete proof equivalent to the main system but for right-to-left inference.

  • Implementation: variants/impl_variant_right2left/ Available

    Haskell implementation of the right-to-left variant.

Top and Bottom Types Extension

  • Proof: variants/proof_core_top_bot/ Available

    Extension of declarative system and matching subtyping with top and bottom types, including all related properties.

Software Requirements

For Agda Proofs

  • Agda (tested version recommended)
  • Agda standard library

For Rocq/Coq Proofs

  • Rocq Prover (or Coq)
  • CoqHammer library

For Haskell Implementations

  • GHC (Glasgow Haskell Compiler)
  • Cabal build system

Getting Started

Recommended Evaluation Order

  1. Implementation First: Start with the Haskell implementation to see the system in action cd main/impl_haskell/Poly && cabal run Poly
  2. Main Proofs: Examine the Agda formalization, starting with the theorem overview
    • Read main/proof_agda/Implicit/README.agda
    • Browse the modular proof structure
  3. Decidability: Check the Rocq decidability proof cd main/decidability_coq/Dec && make
  4. Variants: Explore the right-to-left variant and top/bottom extensions as needed

Paper Correspondence

  • Section 3 theorems: See main/proof_agda/Implicit/README.agda lines 6-15
  • Section 4 theorems: See main/proof_agda/Implicit/README.agda lines 19-31
  • Section 5 theorems: See main/proof_agda/Implicit/README.agda lines 35-42
  • All examples: Run via main/impl_haskell/Poly/

Directory Structure Summary

  • main/proof_agda/ - Main Agda mechanization
  • main/decidability_coq/ - Decidability proof in Rocq/Coq
  • main/impl_haskell/ - Haskell implementation with examples
  • variants/proof_variant_right2left/ - Right-to-left variant proofs
  • variants/impl_variant_right2left/ - Right-to-left implementation
  • variants/proof_core_top_bot/ - Top/bottom types extension
Note: This artifact provides a complete mechanization and implementation of local contextual type inference. All proofs are fully mechanized and all implementations include the examples from the paper. For questions about specific components, consult the individual README files in each directory.
